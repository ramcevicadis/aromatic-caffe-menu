## 🚀 3 Koraka do Live Menija

### 1️⃣ Firebase Setup (15 min)
- Kreirajte Firebase projekat
- Omogućite Firestore i Authentication
- Kopirajte config u `index.html`

**Detaljno:** Pogledajte `DEPLOYMENT.md`

### 2️⃣ Deploy na Vercel (10 min)
- Upload projekat na GitHub ili Vercel
- Povežite vaš domen
- Gotovo!

**Detaljno:** Pogledajte `DEPLOYMENT.md`

### 3️⃣ QR/NFC Setup (15 min)
- Generišite QR kodove
- Programirajte NFC tagove (opciono)
- Postavite na stolove

**Detaljno:** Pogledajte `DEPLOYMENT.md`
